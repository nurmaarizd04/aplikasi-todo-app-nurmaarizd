---

## 🛠️ Setup

1. **Install Dependensi**

   ```bash
   npm install
   ```

2. **Konfigurasi .env**

   Rubah file .env.example menjadi .emv

---

## 🚀 Menjalankan Aplikasi

1. **Development Mode**

   ```bash
   npm run start
   ```

2. **Build untuk Production**

   ```bash
   npm run build
   ```
